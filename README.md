# Sound-Check
SOUND CHECK Android app is a mobile tool designed to help live audio technicians, sound engineers, DJs, bands, and event crews check, configure, and monitor audio systems from an Android phone.

Main features:

🎤 Mic Test – microphone input level / signal detection
🔊 Speaker Test – test left/right output and generate test tones
📊 RTA / Spectrum Analyzer – visualize frequencies in real time
🔈 dB/SPL Meter – approximate sound level using the phone microphone
🎵 Tone Generator – 20 Hz–20 kHz, with selectable frequencies
↔️ Left / Right Test – check stereo channels
🔄 Phase Test – basic polarity/phase checking
🎧 Headphone Test – left/right and frequency sweep
💾 Sound Check Notes – save notes for each event/setup
🎛️ Universal WIFI MixerEngine - Midas, X32, Yamaha TF, A&H SQ, Soundcraft UI, and many more..
